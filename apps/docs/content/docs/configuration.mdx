`still.toml` is desired state for a project. It names the tools, packages, apps,
services, tasks, env values, and agent setup a project expects.

The schema lives in `apps/cli/examples/still.schema.json`, and the longer
example lives in `apps/cli/examples/still.toml`.

## Tools

Tools are language runtimes, toolchains, and command-line developer tools.

```toml
[tools]
node = "22"
python = "3.12"
go = "latest"

[tools.rust]
version = "stable"
source = "rustup"
components = ["rustfmt", "clippy"]
targets = ["wasm32-unknown-unknown"]
```

Short form is enough for simple version pins. Expanded form adds the source and
tool-specific options.

## Packages And Apps

Packages are system-level command-line dependencies. Apps are desktop or
platform applications.

```toml
[packages]
latest = ["pandoc", "ripgrep", "fd", "jq"]
postgresql = { version = "16", source = "auto" }

[apps]
latest = ["docker-desktop", "zed", "firefox"]
visual-studio-code = { source = "auto" }
```

You can give platform-specific names when ecosystems disagree.

```toml
[packages.fd.names]
macos = "fd"
linux = "fd-find"
windows = "fd"
```

You can also choose different sources per platform:

```toml
[packages.llvm]
version = "18"
source = "auto"
sources = { macos = "homebrew", linux = "apt", windows = "winget" }
```

## Environment

Environment values can be written directly or loaded from files.

```toml
[env]
RUST_LOG = "debug"
NODE_ENV = "development"
files = [".env", ".env.local"]
```

Loading env files is trust-sensitive because env files can alter command
behavior.

## Platform Filters

Tools, packages, and apps can limit where they apply.

```toml
[packages.watchman]
version = "latest"
platforms = ["macos", "linux"]
ignore = "windows"
```

Use these fields when a dependency is useful on one platform and noisy or
unavailable on another.

## Generated Files

Still edits user-authored `still.toml` with comment/order preservation where
practical. Still-owned generated files use typed TOML:

- `still.lock.toml`
- `.still/trust.toml`
- install receipt markers
- generated agent metadata
