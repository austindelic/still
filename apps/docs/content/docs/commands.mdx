title: Commands

---

These examples use `still`, the installed command name and the current binary
name in this repository.

## Project Setup

`init` creates a starter project config and trusts the generated file.

```bash
still init
```

`trust` records that you have reviewed project-defined executable behavior.

```bash
still trust
```

Trust is required before Still loads env files, runs tasks, starts services, or
syncs external agent behavior from the project.

## Install And Reconcile

`install` installs typed item requests, records successful requests in config,
and refreshes the lockfile.

```bash
still install --tool cargo:ripgrep@14.1.1
still install --package homebrew:openssl
still install --app flatpak:org.mozilla.firefox
```

Source flags apply to following specs:

```bash
still install --tool --cargo ripgrep@14.1.1 cargo-nextest
still install --package --apt openssl curl
```

`sync` reconciles installed state from `still.toml`.

```bash
still sync
```

`uninstall` removes desired state and related Still-managed artifacts.

```bash
still uninstall --tool cargo:ripgrep@14.1.1
```

## Run And Inspect

`run` executes a child command with the Still-managed environment.

```bash
still run cargo test
```

`task` runs a named task, or lists tasks when no task name is supplied.

```bash
still task lint
still task
```

`services` inspects, starts, stops, or checks configured services.

```bash
still services status
still services check docker
```

`agents` inspects, validates, or syncs configured agent instructions and skills.

```bash
still agents list
still agents check
still agents sync
```

`list`, `env`, `doctor`, `config check`, and `activate` help inspect what Still
sees and how it would prepare the shell.

```bash
still list --all
still env
still doctor
still config check
still activate
```

## Global State

Use `--global` with supported commands to target the global Still config instead
of the nearest project config.

```bash
still install --global --tool cargo:cargo-nextest
still list --global --all
```
