Still is multi-OS first. Config should express project intent; platform adapters and backend adapters translate that intent into host-specific operations.

## Platforms

Valid platform identifiers:

| Identifier | Host family |
| --- | --- |
| `macos` | macOS |
| `linux` | Linux |
| `windows` | Windows |

The engine detects the active host platform. Entries apply to the host through `platforms`, `ignore`, `only`, and platform-specific names.

```toml
[packages.fd.names]
macos = "fd"
linux = "fd-find"
windows = "fd"
```

## Filters

```toml
[packages.watchman]
version = "latest"
platforms = ["macos", "linux"]
ignore = "windows"
```

Filter normalization:

- `platforms` is an allow-list.
- `only` restricts the entry to one platform and replaces the allow-list when present.
- `ignore` excludes one platform after allow-list resolution.

## Backend Selection

`backend` is the scalar fallback. `backends` overrides it per platform.

```toml
[packages.llvm]
version = "18"
backend = "auto"
backends = { macos = "homebrew", linux = "apt", windows = "winget" }
```

`auto` means backend selection, not a concrete backend. The user-facing type is separate from the backend:

| Type | Role | Backend examples |
| --- | --- | --- |
| Tool | Runtime, toolchain, or developer CLI | `mise`, `asdf`, `rustup`, `npm`, `aqua`, `cargo`, `go`, `pipx` |
| Package | System package, library, or command-line package | `homebrew`, `apt`, `dnf`, `pacman`, `winget`, `chocolatey`, `scoop`, `nix` |
| App | Desktop or platform application | `homebrew-cask`, `flatpak`, `winget`, `chocolatey`, platform app sources |

## V1 Backend Direction

Still's v1 backend/provider families include:

| Backend | Direction |
| --- | --- |
| `core` / `native` | Still-managed first-party installers and built-in platform behavior. |
| `github` | GitHub releases, tags, and release assets. |
| `http` | Direct URL downloads with checksum verification. |
| `cargo` | Rust crates installed through Cargo. |
| `go` | Go tools/modules installed through the Go toolchain. |
| `npm` | Node packages installed through npm-compatible metadata. |
| `pipx` | Python CLI tools installed through pipx. |
| `asdf` | Existing asdf plugin ecosystem. |
| `aqua` | Aqua registry/package ecosystem. |
| `homebrew` | Homebrew formulae. |
| `homebrew-cask` | Homebrew casks. |

Backend names in the spec are product direction, not a promise that every backend is implemented today.

## Lockfiles

Still writes one multi-platform-capable `still.lock.toml` next to the selected config.

Current lockfile items record:

- kind
- name
- platform
- version
- backend when selected
- source identity
- desired-state checksum
- expected outputs
- linked executable placeholders

`sync` replaces entries for the active host platform and preserves entries for other platforms. This allows one lockfile to accumulate resolved state across macOS, Linux, and Windows runs.
