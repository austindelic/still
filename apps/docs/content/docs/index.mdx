Still is a package and toolchain manager for projects that need more than a language version file. It is built around a simple idea: the things your project depends on should be named in one place, installed predictably, and easy to inspect.

Today, the CLI can install tools from Homebrew formula data, launch the terminal UI, and parse Still-style tool specs such as `ripgrep` and `ripgrep@14.1.1`. The wider v1 shape is already visible in the config schema: tools, packages, apps, environment files, services, and tasks.

These docs describe both parts with clear labels. Current behavior is written as current behavior. Preview pages describe the intended v1 workflow and the config shape that already exists in the repository.

## What Still Is For

Still is for teams and solo projects that want a repeatable development setup without splitting responsibility across Homebrew, a version manager, shell scripts, and a README full of setup notes.

Use Still when you want to:

- install project tools and system packages from a single command line
- keep runtime versions near the project that needs them
- describe services and tasks next to the tools they depend on
- make setup easier to review, cache, and reproduce

## Current Status

Still is early. The command surface is broader than the implemented behavior, so expect a few commands to print their parsed arguments while the engine catches up. The docs call those areas out as preview instead of pretending they are finished.

The current binary in this repository is named `still_s`. The examples use `still` for the intended installed command name.
