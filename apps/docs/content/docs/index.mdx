Still is a config-first project environment manager. It keeps tools, packages,
apps, env files, services, tasks, and agent setup attached to a project instead
of scattering them across setup scripts and local shell history.

The project is pre-1.0. The docs describe the current command surface and the
source-based architecture the engine is moving toward. When a source installer
is still scaffolding, the docs call that out plainly.

## What Still Is For

Use Still when you want to:

- install project tools, packages, and apps from one command surface.
- keep runtime versions and native dependencies near the code that needs them.
- describe tasks, services, env files, and agent instructions in the same place.
- review setup changes as plain TOML.
- support macOS, Linux, and Windows without forking the project setup story.

## The Core Loop

```bash
still init
still install --tool cargo:ripgrep@14.1.1 --package homebrew:openssl
still sync
still run cargo test
still task lint
```

`still.toml` records desired state. `still.lock.toml` records resolved state.
The engine owns config, trust, source selection, planning, inventory, and
lockfiles. The CLI and TUI only parse input and present results.
