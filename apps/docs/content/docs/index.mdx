Still makes a project directory describe the environment it needs. Commit `still.toml`, run `still sync`, and the same desired state can be resolved on macOS, Linux, and Windows.

```bash
still init
still install --tool jq ripgrep fd --package openssl llvm --app zed firefox
still run cargo test
still task lint
```

## The Core Model

Still has two durable files:

- `still.toml` is desired state. Users edit it directly or let commands such as `still install` update it.
- `still.lock.toml` records resolved state next to the selected config, including platform, backend, version, outputs, and executable links.

Project config wins over global config for the active project. Global config lives at `~/.config/still/config.toml` and is selected explicitly with `--global`, or used by add-style commands when no project config exists.
